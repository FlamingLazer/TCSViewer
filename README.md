# TCS Viewer

Show LEGO Star Wars: The Complete Saga on a second monitor and toggle the viewer with a keyboard shortcut.

## Open and use

1. [Download the latest release](https://github.com/FlamingLazer/TCSViewer/releases) and extract the ZIP.
2. Open **TCSViewer.exe** and accept the Windows administrator prompt.
3. Choose your game executable, output monitor, display mode and shortcut, then click **Save settings**.
4. Open TCS and press **Ctrl + Alt + F10** (or your chosen shortcut) to turn the viewer on or off.

OBS is detected automatically. If your portable OBS copy is not found, start OBS before toggling the viewer.

## Controls

- **Fullscreen:** fills the selected monitor.
- **Borderless window:** shows a smaller window with a selected size and position.
- **Windowed:** adds a title bar so you can drag the viewer around.
- **Shortcut:** toggles capture and the output window. Capture stops when the viewer is off.
- **Save settings:** saves your choices and stops any active viewer. Use the shortcut to reopen it.
- **Close output window:** stops capture.
- **Close control panel:** exits the program.

Your settings are saved in `viewer.ini` beside the executable. Keep this file when updating to preserve your shortcut and display settings.
